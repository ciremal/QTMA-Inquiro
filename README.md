# Inquiro (QTMA 2024-2025)
## 📌 Summary
Inquiro is an AI-powered stock screening platform designed to make investment research easier and more accessible for novice investors. By combining advanced financial data analysis 
with natural language insights, Inquiro helps users filter through hundreds of stocks, discover opportunities, and gain a better understanding of the market without needing deep financial expertise.

# 🛠️ Tech Stack
- Frontend: Next.js, React, Tailwind CSS
- Backend: Python
- Database: Firestore
- AI/LLM: OpenAI API (for financial insights and natural language queries)
- APIs & Data: EDGAR API, Finnhub Stock APIs, Python yfinance
- Authentication: Firebase Auth
- Deployment: Vercel (frontend), AWS (backend services)
